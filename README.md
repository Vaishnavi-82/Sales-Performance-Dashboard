This project showcases an end-to-end Sales Performance Dashboard developed using Excel, MySQL, and Power BI.

The dataset was cleaned and transformed in Excel, structured and analyzed using MySQL, and visualized through an interactive Power BI dashboard.

Key Features:
• Revenue, Profit, Orders, and Customer KPIs
• Monthly Revenue Trend Analysis
• Regional Sales Distribution
• Customer Segment Analysis
• Top 10 Best-Selling Products
• Interactive Filters (Region, Category, Segment)
• Professional Dashboard Design with Dynamic Visualizations

Tools & Technologies:
• Microsoft Excel
• MySQL
• Power BI

Project Outcomes:
• Identified sales trends and business performance patterns
• Compared regional and segment-wise sales performance
• Created an interactive dashboard for data-driven decision making

This project demonstrates practical skills in data cleaning, SQL querying, business intelligence, and dashboard development.
